# Client Recommendations

## Client A – Startup Company

### Recommended Platform: AWS

AWS is recommended because the startup has a limited budget but expects rapid growth. AWS provides scalable services that allow the company to start with smaller resources and increase capacity as its application gains users. AWS also provides many managed services that can reduce the amount of infrastructure the startup needs to maintain. This makes AWS a flexible option for a growing mobile application.

### Possible Services

* Amazon EC2 – application and backend hosting
* Amazon S3 – storage for application files and media
* Amazon RDS – relational database
* Amazon CloudFront – content delivery
* AWS Lambda – serverless application functions

---

## Client B – University

### Recommended Platform: Microsoft Azure

Azure is the most appropriate platform because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's ecosystem and supports hybrid cloud environments. This allows the university to gradually migrate selected services while continuing to use existing infrastructure. It can also simplify identity and access management for users and administrators.

### Possible Services

* Azure Virtual Machines – Windows Server workloads
* Microsoft Entra ID – identity and access management
* Azure Virtual Network – private cloud networking
* Azure SQL Database – database workloads
* Azure Blob Storage – cloud file and object storage

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud

Google Cloud is recommended because the company develops Artificial Intelligence and Machine Learning applications requiring high-performance computing. Google Cloud provides AI-focused infrastructure and services that can support demanding workloads. It also provides tools for machine learning, data processing, and GPU-accelerated computing. Google Kubernetes Engine can additionally support containerized AI applications.

### Possible Services

* Google Compute Engine – high-performance virtual machines
* Vertex AI – AI and machine learning development
* Google Kubernetes Engine – container orchestration
* Cloud Storage – datasets and model storage
* BigQuery – large-scale data analytics

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is recommended because the company serves customers worldwide and requires highly available infrastructure with automatic scaling. AWS provides multiple Regions and Availability Zones that can be used to design resilient applications. Services such as Elastic Load Balancing and Auto Scaling can distribute traffic and adjust resources according to demand. This architecture can help the e-commerce company handle traffic increases during busy periods.

### Possible Services

* Amazon EC2 – application servers
* Elastic Load Balancing – traffic distribution
* EC2 Auto Scaling – automatic capacity adjustment
* Amazon RDS – relational database
* Amazon CloudFront – global content delivery
* Amazon S3 – object storage
