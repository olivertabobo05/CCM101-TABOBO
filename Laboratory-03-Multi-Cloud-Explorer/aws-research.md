# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a major cloud computing platform provided by Amazon. It offers cloud services for computing, storage, databases, networking, security, analytics, artificial intelligence, application development, and many other areas. AWS uses a pay-as-you-go model, allowing organizations to use cloud resources without purchasing and maintaining all of the physical hardware themselves.

AWS provides more than 200 cloud services, giving organizations a wide range of choices for building and operating applications.

## Global Infrastructure

AWS operates a worldwide infrastructure organized into geographic Regions and Availability Zones. A Region represents a separate geographic area, while Availability Zones are isolated locations within a Region. AWS recommends using multiple Availability Zones when designing highly available applications because workloads can continue operating even if one Availability Zone experiences a failure.

AWS currently lists 39 geographic Regions and 124 Availability Zones, with additional infrastructure planned.

## Cloud Management Console

The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources. Administrators can access services such as EC2, S3, VPC, IAM, databases, monitoring tools, and many other services through the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that organizations can use to run applications, websites, databases, and other workloads.

### 2. Amazon S3

Amazon Simple Storage Service (S3) provides scalable object storage for files, backups, application data, images, videos, and other objects.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create logically isolated networks in AWS. It provides control over IP addresses, subnets, routing, and network security.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls who can access AWS resources and what actions they are allowed to perform.

## Three Advantages

1. **Wide range of services** – AWS provides a very large selection of cloud services for different technical and business requirements.
2. **Global infrastructure** – Its Regions and Availability Zones allow organizations to deploy applications closer to users and design highly available systems.
3. **Scalability** – Organizations can increase or decrease cloud resources based on workload requirements instead of purchasing permanent physical infrastructure.

## Typical Enterprise Use Cases

AWS can be used by enterprises for:

* Web and mobile application hosting
* Data backup and disaster recovery
* E-commerce platforms
* Enterprise databases
* Big data and analytics
* Artificial intelligence and machine learning
* Global applications
* Software development and testing
* Content delivery
