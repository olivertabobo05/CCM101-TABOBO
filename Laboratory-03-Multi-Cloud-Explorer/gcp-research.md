# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is Google's cloud computing platform. It provides services for computing, storage, networking, databases, artificial intelligence, machine learning, containers, data analytics, and application development.

Google Cloud is particularly well known for its data, artificial intelligence, machine learning, and Kubernetes-related technologies.

## Global Infrastructure

Google Cloud organizes its infrastructure into regions and zones. Regions are geographic locations, while zones are isolated infrastructure locations within regions.

As of August 2026, Google Cloud lists 43 regions and 130 zones across its global infrastructure. Google Cloud also operates a global network connecting more than 200 countries and territories.

Google Cloud regions are designed to support high availability, low latency, and data residency requirements.

## Cloud Management Console

The Google Cloud Console is a web-based management interface for creating and managing Google Cloud resources. Users can manage virtual machines, storage, networks, databases, Kubernetes clusters, IAM permissions, and other services through the console.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that can run Linux and Windows workloads in Google Cloud.

### 2. Cloud Storage

Cloud Storage provides scalable object storage for application data, backups, files, media, and other objects.

### 3. Google Virtual Private Cloud

Google Cloud VPC provides networking capabilities for connecting and securing cloud resources.

### 4. Cloud IAM

Cloud Identity and Access Management allows administrators to control which users and services have access to Google Cloud resources. IAM uses roles and permissions to control access.

## Three Advantages

1. **Strong AI and machine learning capabilities** – Google Cloud provides extensive AI infrastructure and services.
2. **Kubernetes expertise** – Google created Kubernetes, and Google Kubernetes Engine (GKE) provides managed Kubernetes capabilities.
3. **Global network** – Google Cloud operates a large global network designed for high performance and low latency.
