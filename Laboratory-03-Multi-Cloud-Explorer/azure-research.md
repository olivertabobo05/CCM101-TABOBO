# Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides services for computing, storage, databases, networking, artificial intelligence, security, identity, analytics, application development, and hybrid cloud environments.

Azure is particularly useful for organizations that already use Microsoft technologies because it integrates with many Microsoft products and enterprise environments.

## Global Infrastructure

Azure has a large worldwide infrastructure consisting of geographic regions and data centers. Microsoft currently lists more than 80 Azure regions and more than 500 datacenters. Azure's global infrastructure is designed to support low latency, data residency, compliance, scalability, and high availability.

Azure geographies contain one or more regions and are designed to address requirements such as data residency and compliance.

## Cloud Management Console

The Microsoft Azure portal is a web-based management interface used to create, configure, monitor, and manage Azure resources. Users can manage virtual machines, storage accounts, databases, networks, identities, applications, and other services from the portal.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable virtual servers for running Windows or Linux applications in the cloud.

### 2. Azure Blob Storage

Azure Blob Storage provides scalable object storage for unstructured data such as documents, images, videos, backups, and application files.

### 3. Azure Virtual Network

Azure Virtual Network allows organizations to create private networks in Azure and connect cloud resources securely.

### 4. Microsoft Entra ID

Microsoft Entra ID provides identity and access management. It helps organizations manage users, applications, devices, and access to cloud resources.

## Three Advantages

1. **Microsoft integration** – Azure works particularly well with Microsoft's enterprise technologies and services.
2. **Hybrid cloud capabilities** – Azure supports environments that combine on-premises infrastructure and cloud resources.
3. **Global infrastructure** – Azure provides a large number of regions and datacenters for global deployment, data residency, and low-latency applications.

## Typical Enterprise Use Cases

Azure can be used for:

* Windows Server migration
* Microsoft 365-related enterprise environments
* Active Directory and identity management
* Enterprise web applications
* Database hosting
* Hybrid cloud infrastructure
* Artificial intelligence
* Data analytics
* Virtual desktops
* Business applications
