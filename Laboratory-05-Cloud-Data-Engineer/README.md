# Laboratory 05 – Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud object storage. The mission is to deploy an S3-compatible object storage server using MinIO and Docker, access its web console, create a storage bucket named `client-photos`, and upload a test file. The activity demonstrates how cloud applications can store large amounts of unstructured data such as user-uploaded images.

## Objectives

* Differentiate between Block, File, and Object Storage.
* Deploy an S3-compatible Object Storage server (MinIO) using Docker.
* Access a cloud service through a web interface using port forwarding.
* Create a storage bucket and upload an object to the cloud.
* Document cloud storage operations using Markdown.
* Maintain a professional GitHub Cloud Computing Portfolio.

## Tools Used

* KillerCoda Playground
* Ubuntu/Docker environment
* Docker
* MinIO
* GitHub
* Modern web browser
* Stable Internet connection

## Skills Learned

* Comparing Block, File, and Object Storage.
* Deploying a containerized cloud storage service using Docker.
* Using environment variables in Docker.
* Accessing a cloud service through a forwarded port.
* Creating and managing an object storage bucket.
* Uploading objects through a web interface.
* Documenting technical procedures using Markdown.
* Organizing a cloud computing portfolio on GitHub.
